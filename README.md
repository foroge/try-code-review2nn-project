# try-code-review2nn-project

Учебный проект, посвященный практике **Code Review** и разработке **Unit-тестов** для приложений на C++.

Проект был выполнен в рамках изучения процессов коллективной разработки и тестирования программного обеспечения.

---

## Цель проекта

В ходе работы необходимо было провести ревью существующего C++-кода, выявить потенциальные проблемы, предложить улучшения и разработать набор unit-тестов, обеспечивающий проверку корректности работы реализованных функций.

---

## Что было выполнено

- анализ существующего исходного кода;
- проведение Code Review через Pull Request;
- поиск логических ошибок и потенциальных проблем;
- подготовка замечаний по улучшению качества кода;
- разработка тестовых сценариев;
- написание Unit-тестов для основных функций проекта;
- проверка корректности работы функций на различных наборах входных данных.

---

## Объекты тестирования

В проекте рассматривались функции, связанные с:

- обработкой чисел;
- проверкой числовых свойств;
- поиском простых чисел;
- вычислительными алгоритмами;
- геометрическими вычислениями.

---

## Используемые технологии

- C++
- Visual Studio
- Git
- GitHub Pull Requests
- Unit Testing

---

## Полученные навыки

В ходе выполнения проекта были получены практические навыки:

- проведения Code Review;
- анализа качества программного кода;
- поиска потенциальных дефектов;
- разработки тест-кейсов;
- написания Unit-тестов;
- работы с системой контроля версий Git и Pull Request.
